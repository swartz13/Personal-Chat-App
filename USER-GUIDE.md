# Chat App — Phone Installation

Hello! This application is designed specifically for your group. Only authorized members can access it. Installation takes about 2 minutes.

## 1. Download the File

Tap on the **app-release.apk** file sent to you.

## 2. Allow Installation

Android might warn you saying "Install unknown apps is not allowed from this source". This is normal — it appears because the app is not on the Play Store.

- Tap the **Settings** button
- Turn on the **Allow from this source** option
- Go back and tap **Install**

## 3. Sign In

Sign in using the email and password provided to you. You only need to sign in once; it will stay logged in.

## 4. Grant Permissions

When the app is opened for the first time, it will ask for permission to send notifications. Tap **Allow** — otherwise, you won't be notified when a message arrives.

When you want to send a photo, it will ask for gallery permission, and when you make a call, it will ask for camera and microphone permissions. You need to allow all of them to use these features.

---

## What You Can Do

| Action | How To |
|---|---|
| Write a message | Type in the box at the bottom, tap **Send** |
| Send photo/video | Tap the **+** button at the bottom left |
| Video call | Tap the camera icon at the top, then select who to call |
| Voice call | Tap the phone icon at the top |

## Important

**Do not "Force stop" the app from settings.** If you do, Android will stop sending notifications and you won't know when messages arrive. Closing it normally (returning to the home screen or swiping it away) is fine.

## Troubleshooting

- **Messages are not arriving:** Check your internet connection
- **Notifications are not arriving:** Settings > Apps > Chat App > Notifications must be turned on
- **Call doesn't connect:** Both parties need to be connected to the internet
